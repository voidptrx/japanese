# 日本語 — Japanese

My journey from Japanese 0 → JLPT N5 → N1.

## Goals

- Understand Japanese grammar structurally
- Read Japanese without relying on romaji
- Build a strong vocabulary and kanji foundation
- Understand basic spoken Japanese
- Reach JLPT N5 and continue toward N1

## Learning philosophy

- Understand before memorizing
- Learn grammar through examples
- Learn vocabulary in context
- Learn kanji through words
- Record mistakes
- Review regularly

## Current level

Pre-N5 - Beginner (working toward JLPT N5)

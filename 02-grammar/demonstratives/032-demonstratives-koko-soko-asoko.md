# Lesson 032 - Demonstratives: ここ, そこ, あそこ

## 1. What I Learned

- I learned how Japanese demonstratives refer to locations.
- I understand the basic meanings of **ここ**, **そこ** and **あそこ**.
- I understand their relationship to the speaker and listener.
- I can distinguish location demonstratives from object demonstratives.
- I understand that location demonstratives can stand independently.
- I can use location demonstratives with familiar particles.
- I can identify location expressions in Japanese sentences.
- I can use location demonstratives in noun sentences, verb sentences and polite questions.

## 2. What Are Location Demonstratives?

Japanese uses the **こ・そ・あ・ど** system to refer to people, objects, places and other concepts.

The location demonstratives introduced in this lesson are:

| Japanese | English                           | Basic Reference   |
| -------- | --------------------------------- | ----------------- |
| ここ     | here; this place                  | Near the speaker  |
| そこ     | there; that place                 | Near the listener |
| あそこ   | over there; that place over there | Away from both    |

These words identify locations.

Unlike この, その and あの, they do not require a following noun.

<u>Example:</u>

ここ = here\
そこ = there\
あそこ = over there

Their basic meanings depend on the location of the speaker and listener.

**ここ** refers to the speaker's location or an area near the speaker.

<u>Example:</u>

ここはがっこうです。= This place is a school.

**そこ** refers to a place near the listener or a location associated with the listener.

<u>Example:</u>

そこはがっこうです。= That place is a school.

**あそこ** refers to a place away from both the speaker and the listener.

<u>Example:</u>

あそこはがっこうです。= That place over there is a school.

These are the basic physical meanings. Actual reference also depends on context.

## 3. Cure Dolly's Explanation

Cure Dolly discusses the こ・そ・あ・ど system in Chapter 20, "Directionals: それ・その・そんな・そう etc."

She begins with the location expressions:

- ここ
- そこ
- あそこ
- どこ

Her explanation connects these words to the speaker's and listener's perspectives.

The basic directional relationships are:

- こ: associated with the speaker
- そ: associated with the listener
- あ: away from both
- ど: interrogative, asking which or where

For location expressions, these relationships produce:

ここ = here\
そこ = there\
あそこ = over there\
どこ = where

The important idea is that the same directional system appears throughout Japanese demonstratives.
Cure Dolly also emphasizes that the system can extend beyond physical distance into conversational and abstract reference.
The physical-location model provides the foundation for this lesson.

The interrogative form どこ will be studied separately.

## 4. Location Demonstratives as Independent Expressions

Location demonstratives identify places without requiring a following noun.

Compare:

ここ = this place\
このほん = this book

The word ここ independently identifies a location.
The word この modifies the noun ほん.
The grammatical functions are different.

Location demonstratives can be followed by particles, just like other noun-like expressions.

<u>Example:</u>

ここは = as for this place\
そこに = at that place\
あそこで = at that place over there

The particle determines the grammatical relationship of the location to the sentence.

## 5. Location Demonstratives with に

The particle に can mark the location where a person, animal or object exists.

Basic pattern:

Location + に + Existence Verb

With people and animals, the familiar polite existence verb is います.

<u>Example:</u>

ねこはここにいます。= The cat is here.

Sentence analysis:

| Component | Function              |
| --------- | --------------------- |
| ねこは    | Topic                 |
| ここに    | Location of existence |
| います    | Predicate             |

ここ refers to the speaker's location.

に marks that location as the place where the cat exists.

<u>Example:</u>

せんせいはそこにいます。= The teacher is there.

| Component  | Function              |
| ---------- | --------------------- |
| せんせいは | Topic                 |
| そこに     | Location of existence |
| います     | Predicate             |

<u>Example:</u>

ねこはあそこにいます。= The cat is over there.

The structure remains the same.

The location demonstrative changes, but に continues to mark the place of existence.

## 6. Location Demonstratives with で

The particle で can mark the place where an action takes place.

Basic pattern:

Location + で + Action

<u>Example:</u>

せんせいはここでほんをよみます。= The teacher reads a book here.

Sentence analysis:

| Component  | Function               |
| ---------- | ---------------------- |
| せんせいは | Topic                  |
| ここで     | Location of the action |
| ほんを     | Object                 |
| よみます   | Predicate              |

ここ refers to the speaker's location.

で marks that location as the place where the reading action occurs.

<u>Example:</u>

せんせいはあそこでほんをよみます。= The teacher reads a book over there.

| Component  | Function               |
| ---------- | ---------------------- |
| せんせいは | Topic                  |
| あそこで   | Location of the action |
| ほんを     | Object                 |
| よみます   | Predicate              |

The location demonstrative identifies the place.

The particle で indicates the relationship between that place and the action.

## 7. The Difference Between に and で

| Expression | Function              |
| ---------- | --------------------- |
| ここに     | Location of existence |
| ここで     | Location of an action |
| そこに     | Location of existence |
| そこで     | Location of an action |
| あそこに   | Location of existence |
| あそこで   | Location of an action |

The distinction comes from the particles and the grammatical relationship expressed by the predicate.
It does not come from the location demonstrative itself.

## 8. Location Demonstratives with は

Location demonstratives can function as the topic of a sentence.

Basic pattern:

Location + は + Predicate

<u>Example:</u>

ここはがっこうです。= This place is a school.

Sentence analysis:

| Component    | Function               |
| ------------ | ---------------------- |
| ここ         | Location demonstrative |
| は           | Topic particle         |
| がっこうです | Predicate              |

The complete topic is ここ.
The predicate identifies the place as a school.

<u>Example:</u>

あそこはせんせいのがっこうです。= That place over there is the teacher's school.

| Component              | Function  |
| ---------------------- | --------- |
| あそこは               | Topic     |
| せんせいのがっこうです | Predicate |

The location demonstrative can therefore participate in familiar noun-sentence patterns.

## 9. Location Demonstratives in Negative Sentences

Location demonstratives can also appear in negative noun sentences.

<u>Example:</u>

ここはせんせいのがっこうではありません。= This place is not the teacher's school.

Sentence analysis:

| Component                        | Function           |
| -------------------------------- | ------------------ |
| ここは                           | Topic              |
| せんせいのがっこうではありません | Negative predicate |

The location demonstrative establishes the place being discussed.
The predicate provides the negative identification.
The familiar negative noun-sentence structure remains unchanged.

## 10. Location Demonstratives in Questions

The polite question particle か can be used with sentences containing location demonstratives.

<u>Example:</u>

ここはがっこうですか。= Is this place a school?

Sentence analysis:

| Component    | Function          |
| ------------ | ----------------- |
| ここは       | Topic             |
| がっこうです | Predicate         |
| か           | Question particle |

<u>Example:</u>

ねこはそこにいますか。= Is the cat there?

| Component | Function              |
| --------- | --------------------- |
| ねこは    | Topic                 |
| そこに    | Location of existence |
| います    | Predicate             |
| か        | Question particle     |

The location demonstrative identifies the place.
The particle に marks the location of existence.
The sentence-final か marks the question.

## 11. Comparing the Three Demonstrative Groups

The previously introduced demonstrative groups share the same basic こ・そ・あ relationships.

However, they have different grammatical functions.

| Function                       | Near Speaker | Near Listener | Away from Both |
| ------------------------------ | ------------ | ------------- | -------------- |
| Independent object reference   | これ         | それ          | あれ           |
| Noun modification              | この         | その          | あの           |
| Independent location reference | ここ         | そこ          | あそこ         |

Compare these sentences:

これはほんです。= This is a book.\
これ independently refers to an object.

このほんはわたしのほんです。= This book is my book.\
この modifies the following noun ほん.

ここはがっこうです。This place is a school.\
ここ independently refers to a location.

These expressions share the same basic proximity relationship but differ in what they refer to and how they function grammatically.
The same distinction applies to the そ and あ groups.

## 12. Important Concepts

- ここ, そこ and あそこ are location demonstratives.
- They belong to the Japanese こ・そ・あ・ど system.
- ここ refers to the speaker's location or a nearby place.
- そこ refers to the listener's location or a place associated with the listener.
- あそこ refers to a place away from both in the basic physical model.
- Location demonstratives can stand independently.
- They do not require a following noun.
- Location demonstratives work with familiar affirmative, negative and question structures.
- ここ, この and これ have different grammatical functions.
- The same distinction applies to the そ and あ groups.
- Physical distance provides a useful foundation, but context can also determine demonstrative reference.
- The related question word どこ belongs to the same system and will be studied separately.

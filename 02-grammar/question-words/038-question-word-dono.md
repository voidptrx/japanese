# Lesson 038 - Question Word: どの

## 1. What Is どの?

どの means "which" and is used directly before a noun.

It asks which particular person or thing is meant,
usually among identifiable alternatives.

| Expression | Meaning              |
| ---------- | -------------------- |
| この本     | This book            |
| その本     | That book            |
| あの本     | That book over there |
| どの本     | Which book?          |

どの must normally be followed by a noun.
It does not independently replace the noun.

## 2. The こ・そ・あ・ど System

| Independent | Noun-modifying |
| ----------- | -------------- |
| これ        | この           |
| それ        | その           |
| あれ        | あの           |
| どれ        | どの           |

Cure Dolly distinguishes the れ-group from the の-group.

The れ-group can refer independently to things.
The の-group modifies a following noun.

This is a useful structural analogy, not a universal
word-formation rule.

## 3. どの with Particles

どの + noun forms a noun phrase.
Particles attach to the complete phrase according to its role.

**Example:**

先生はどの本を読みますか。= Which book does the teacher read?

どの先生が本を読みますか。= Which teacher reads books?

先生の友達はどの学校で勉強しますか。= At which school does the teacher's friend study?

- どの本を: Questioned object
- どの先生が: Questioned subject
- どの学校で: Questioned action location

## 4. Topic vs. Subject

**Compare:**

先生はどの本を読みますか。= Which book does the teacher read?\
どの先生が本を読みますか。= Which teacher reads books?

In the first sentence, the teacher is the known topic.
In the second, the identity of the teacher is questioned.

が is the natural choice for neutral subject-identification
questions.

は is not universally forbidden with どの, but its use
depends on the discourse context.

## 5. どの in Nested Noun Phrases

**Example:**

どの先生の友達が本を読みますか。= Which teacher's friend reads books?

Structure:

[どの先生の友達] が

- どの modifies 先生.
- の connects 先生 to 友達.
- 友達 is the head noun.
- が marks the complete noun phrase as the subject.

## 6. どの vs. 何の vs. 誰の

| Expression | Meaning            | Asks about            |
| ---------- | ------------------ | --------------------- |
| どの本     | Which book?        | Selection / identity  |
| 何の本     | What kind of book? | Type / subject matter |
| 誰の本     | Whose book?        | Ownership             |

**Example:**

どの本が先生の本ですか。= Which book is the teacher's?

この本は何の本ですか。= What kind of book is this?

この本は誰の本ですか。= Whose book is this?

## 7. Important Concepts

- どの means "which" and directly modifies a noun.
- どの + noun forms a complete noun phrase.
- Particles follow the phrase according to its grammatical role.
- どの asks which one among alternatives.
- 何の asks about type or subject matter.
- 誰の asks about ownership.

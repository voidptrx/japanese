# Lesson 039 - Question Word: どれ

## 1. What Is どれ?

どれ means "which one?" and asks which item is meant
among identifiable alternatives.

Unlike どの, it can stand independently without a following noun.

**Example:**

どれが先生の本ですか。= Which one is the teacher's book?

## 2. どれ vs. どの

| Form   | Meaning     | Usage           |
| ------ | ----------- | --------------- |
| どれ   | Which one?  | Independent     |
| どの本 | Which book? | Modifies a noun |

**Compare:**

どの本が五百円ですか。= Which book is 500 yen?\
どれが五百円ですか。= Which one is 500 yen?

Both are correct when the context identifies the available items.

## 3. The こ・そ・あ・ど System

| Independent | Noun-modifying |
| ----------- | -------------- |
| これ        | この           |
| それ        | その           |
| あれ        | あの           |
| どれ        | どの           |

Cure Dolly describes these as the れ-group and の-group.

The れ-group refers independently to things.
The の-group modifies nouns.

This is a structural learning aid, not a universal word-formation rule.

## 4. どれ with Particles

どれ functions like a noun phrase and takes particles
according to its grammatical role.

**Example:**

どれが先生の本ですか。= Which one is the teacher's book?

先生はどれを読みますか。= Which one does the teacher read?

- どれが: Questioned subject
- どれを: Questioned object

For neutral subject-identification questions,
が is the natural choice.

## 5. Topic vs. Subject

**Compare:**

どれが先生の本ですか。= Which one is the teacher's book?\
先生の本はどれですか。= Which one is the teacher's book?

The first sentence asks which item is the subject.
The second makes 先生の本 the topic and asks which item corresponds to it.

The translations are similar, but the information
structures differ.

## 6. Common Mistakes

| Incorrect | Correct |
| --------- | ------- |
| どれ本    | どの本  |
| どのが    | どれが  |
| どのを    | どれを  |

どの needs a following noun.
どれ stands independently.

## 7. Important Concepts

- どれ means "which one?"
- どれ is independent; どの modifies a noun.
- どれが asks which item is the subject.
- どれを asks which item is the object.
- どれ and どの can express similar selections but require different grammatical structures.
- は and が depend on the sentence's information structure.
- Context identifies the set of possible choices.

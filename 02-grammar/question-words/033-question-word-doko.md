# Lesson 033 - Question Word: どこ

## 1. What I Learned

- The meaning and grammatical function of **どこ**.
- How **どこ** fits into the こ・そ・あ・ど system.
- How to ask about locations with どこますか.
- How **どこ** works with に, で and へ.
- How to distinguish location, action and destination questions.

## 2. What is どこ?

**どこ** means "where" or "which place".
It is the interrogative member of the location demonstrative group.

| Word   | Meaning                   |
| ------ | ------------------------- |
| ここ   | Here                      |
| そこ   | There (near the listener) |
| あそこ | Over there                |
| どこ   | Where?                    |

The first three identify locations. **どこ** asks which location is being referred to.

## 3. Cure Dolly's Explanation

In chapter 20, Cure Dolly explains **どこ** as part of the Japanese こ・そ・あ・ど system.

The ど-group introduces a question:

- こ: speaker-associated
- そ: listener-associated
- あ: distant from both
- ど: interrogative

Like ここ, そこ and あそこ, どこ functions as an independent location expression.

Tae Kim's Grammar Guide also uses **どこ** in location questions with familiar Japanese sentence structures and particles.

## 4. どこ with Different Particles

The grammatical relationship is determined by the particle and predicate.

| Pattern    | Function                            | Example                  |
| ---------- | ----------------------------------- | ------------------------ |
| どこですか | Asks for a location                 | がっこうはどこですか。   |
| どこに     | Asks about existence or destination | ねこはどこにいますか。   |
| どこで     | Asks where an action occurs         | どこでほんをよみますか。 |
| どこへ     | Asks about movement direction       | どこへいきますか。       |

<u>Example:</u>

がっこうはどこですか。= Where is the school?

The predicate どこです asks for the school's location.

<u>Example:</u>

ねこはどこにいますか。= Where is the cat?\
ほんはどこにありますか。= Where is the book?

います is used for people and animals, あります is used for inanimate objects.

With movement verbs, に can also mark a destination.

<u>Example:</u>

せんせいはどこでほんをよみますか。= Where does the teacher read a book?

で marks the location where an action occurs

<u>Example:</u>

せんせいはどこへいきますか。= Where is the teacher going?

へ marks the direction of movement.
どこにいきますか is also possible, with に marking the destination.

## 5. Sentence Analysis

<u>Example:</u>

せんせいはどこでにほんごをべんきょうしますか。= Where does the teacher study Japanese?

| Component        | Function                   |
| ---------------- | -------------------------- |
| せんせいは       | Topic                      |
| どこで           | Questioned action location |
| にほんごを       | Object                     |
| べんきょうします | Predicate                  |
| か               | Question particle          |

The question word remains inside the sentence, in the position of the location expression.

Compare:

せんせいはここでべんきょうします。= The teacher studies here.\
せんせいはどこでべんきょうしますか。= Where does the teacher study?

## 6. Important Distinctions

- どこにいますか: asks where someone is.
- どこにありますか: asks where something is.
- どこでべんきょうしますか: asks where studying happens.
- どこへいきますか: asks where someone is going.
- どこにいきますか: asks about the destination.

**どこ** does not determine the particle. The grammatical relationship expressed by the sentence determines the particle.

## 7. Important Concepts

- **どこ** is an independent interrogative location word.
- It belongs to the こ・そ・あ・ど system.
- It does not require a following noun.
- どこですか directly asks for a location.
- The question word stays in its grammatical position.

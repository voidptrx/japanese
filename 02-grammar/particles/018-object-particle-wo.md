# Lesson 018 - Object Particle を

## 1. What I learned

- I learned that `を` marks the direct object of a verb.
- I understand the difference between `が` and `を`.
- I learned that not all Japanese verbs take direct objects.
- I learned the basic distinction between transitive and intransitive verbs.
- I understand that subjects and objects can be omitted when context makes them clear.
- I learned that particles identify grammatical roles even when word order changes.
- I understand how `を` and `は` interact when an object becomes the topic.

## 2. What is the Object Particle を?

The particle `を` marks the direct object of a verb.

Example:

さくらがパンをたべます。= Sakura eats bread / will eat bread.

- さくらが = Sakura (subject)
- パンを = bread (direct object)
- たべます = eats / will eat (predicate)

The subject performs the action. The direct object is the thing the action is directed toward.

> [!IMPORTANT]
>
> - The particle is written `を`.
> - In modern standart Japanese, it is pronounced "o".
> - It is commonly typed as "wo" using a Japanese IME.
> - It is not written お when functioning as the object particle.

## 3. Cure Dolly's Train Model

Cure Dolly uses a train analogy to explain Japanese sentence structure. The main carriage represents
the subject. The engine represents the predicate. An additional white carriage can provide information
about the action, such as its direct object.

Example:

わたしがケーキを食べる。= I eat cake.

- わたしが = subject
- ケーキを = direct object
- 食べる = predicate

The object tells us what is being eaten.

The basic subject-predicate relationship is still distinguishable from the object's role.

Cure Dolly also uses an "invisible carriage" model to explain information omitted from a sentence.

> [!IMPORTANT]
> This is an explanatory model. An omitted subject does not mean that a literal invisible `が`
> particle must be inserted. Context determines who performs an actions.

## 4. Subject が vs. Object を

Compare their functions:

`が` marks the grammatical subject.\
`を` marks the direct object.

Example:

さくらがほんをよみます。= Sakura reads a book / will read a book.

- さくらが = who reads (subject)
- ほんを = what is read (direct object)
- よみます = reading action (predicate)

These particles have different grammatical roles.

## 5. Transitive Verbs

Transitive verbs can take direct objects.

Example:

パンをたべます。= Eat bread / eats bread, depending on context.\
みずをのみます。= Drink water / drinks water, depending on context.\
ほんをよみます。= Read a book / reads a book, depending on context.

The verbs たべます, のみます, よみます are transitive verbs.

> [!IMPORTANT]
> A direct object does not have to be physically changed by an action.
> For example, ほん is still the direct object of よみます.

## 6. Intransitive Verbs

Intransitive verbs do not take direct objects.

Example:

さくらがきます。= Sakura comes / will come.

- さくらが = subject
- きます = predicate

There is no direct object. The verb きます is intransitive.

Example:

ねこがいます。= There is a cat.\
ほんがあります。= There is a book.

The verbs います and あります do not take direct objects in these existence construction.

## 7. Omitted Subjects and Objects

Japanese frequently omits information that can be understood from context.

Compare:

さくらがパンをたべます。= Sakura eats bread.\
パンをたべます。= Someone eats bread, depending on context.\
たべます。= Someone eats something, depending on context.

The final sentence does not explicitly identify either the subject or the object.

Example dialogue:

A: このほんをよみますか。\
&nbsp;&nbsp;&nbsp;Will you read this book?

B: はい、よみます。\
&nbsp;&nbsp;&nbsp;Yes, I will.

The answer does not need to repeat the known subject or object.

Do not automatically assume that an omitted subject is わたし.

## 8. Word Order and Particles

A common Japanese sentence pattern is:

Subject + が + Object + を + Predicate

Example:

さくらがほんをよみます。

Another possible order is:

ほんをさくらがよみます。

Both sentences identify:

- さくら = subject
- ほん = direct object
- よみます = predicate

The particles preserve the grammatical roles. However, word order is not meaningless.
Different orders may affect information structure, focus and naturalness depending on context.
The predicate normally appears at the end in ordinary Japanese sentences.

## 9. Object を vs. Topic は

`を` marks the direct object. `は` marks the topic.

Compare:

みずをのみます。= Drink water.\
みずはのみます。= As for water, I drink it.

In the second sentence, みず is presented as the topic.
It can still be understood as the thing being drunk.

When a direct object is topicalized with は, は normally replaces を.

Correct:

- みずをのみます。
- みずはのみます。

Incorrect in this standard pattern:

- みずをはのみます。

> [!IMPORTANT]
>
> - は does not become an object marker.
> - を and は have different functions.
> - Contrast may be implied by は, depending on context.
> - Contrast is not required in every sentence using は.

## 10. Topic, Subject, Object and Predicate

Example:

きょうはさくらがほんをよみます。= Sakura will read a book today.

- きょうは = topic
- さくらが = subject
- ほんを = direct object
- よみます = predicate

These elements have different functions. A topic provides the conversational frame.
A subject is grammatically connected to the predicate.
A direct object is an argument of the verb.
The predicate states the action or condition.
Not every sentence needs to express all these elements explicitly.

## 11. Important Concepts

- `を` marks the direct object.
- `を` is written "wo" in romaji but pronounced "o"
  in modern standard Japanese.
- `が` marks the grammatical subject.
- `は` marks the topic.
- Transitive verbs can take direct objects.
- Intransitive verbs do not take direct objects.
- Subjects and objects may be omitted when understood from context.
- Particles continue to identify grammatical roles when word order changes.
- Word order can still affect naturalness and focus.
- An object presented as the topic can still be the semantic object of an action.

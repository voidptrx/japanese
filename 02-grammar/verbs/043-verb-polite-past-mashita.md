# Lesson 043 — Polite Past Verb Form (～ました)

## 1. Polite Past (～ました)

The ～ました form expresses polite, affirmative past tense.

| Non-Past | Past       |
| -------- | ---------- |
| 読みます | 読みました |
| 書きます | 書きました |
| 食べます | 食べました |
| 来ます   | 来ました   |

Both forms are polite. Their primary difference is tense.

- 読みます = reads / will read
- 読みました = read (past)

## 2. Formation

Use the same ます-stem and replace ます with ました.

読む => 読み

- 読み + ます => 読みます
- 読み + ました => 読みました

### Godan (五段動詞)

- 読む => 読みました
- 書く => 書きました
- 行く => 行きました

### Ichidan (一段動詞)

- 食べる => 食べました
- 見る => 見ました

### Irregular Verbs

- する => しました
- 来る（くる）=> 来ました（きました）

## 3. Tense and Polarity

|          | Affirmative | Negative        |
| -------- | ----------- | --------------- |
| Non-past | 読みます    | 読みません      |
| Past     | 読みました  | Not yet studied |

～ません remains non-past even when combined with a past-tense clause.

Past negative (～ませんでした) is a separate conjugation.

## 4. Connecting Clauses with が

が can connect two clauses and express contrast, often translated as "but" or "although".

**Example:**

学校に来ましたが、本を読みません。= Came to school, but does not / will not read a book.

This connecting が differs from the subject-marking が.

## 5. Example Sentences

先生は学校で本を読みました。= The teacher read a book at school.

この人は本を書きました。= This person wrote a book.

日本人は学校に来ました。= The Japanese person came to school.

どの先生の友達が学校に来ましたか。= Which teacher's friend came to school?

何をしましたか。= What did you do?

## 6. Important Concepts

- ～ました is polite, affirmative, and past.
- ～ます and ～ました use the same verb stem.
- Verb groups determine how the stem is formed.
- Particles keep their usual functions in past-tense sentences.
- Different clauses can contain different tense forms.

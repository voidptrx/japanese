# Lesson 049 — Plain Past Negative Verb Form (～なかった)

## 1. Plain Past Negative Verb Form

The ～なかった form expresses plain past negation: an action did not happen.

**Examples:**

- 読まない => 読まなかった = did not read
- 食べない => 食べなかった = did not eat
- 行かない => 行かなかった = did not go

It is the plain equivalent of the polite ～ませんでした form.

## 2. Core Transformation

Start with the plain negative ～ない form.

Replace the final い with かった:

- ない => なかった
- 読まない => 読まなかった
- 買わない => 買わなかった

Do not derive the past negative from the affirmative ～た form.

**Compare:**

- 読む => 読んだ (past affirmative)
- 読む => 読まない => 読まなかった (past negative)

## 3. Godan Verbs

First form the plain negative using the A-row ending, then change ない to なかった.

| Dictionary Form | Plain Negative | Past Negative |
| --------------- | -------------- | ------------- |
| 読む            | 読まない       | 読まなかった  |
| 書く            | 書かない       | 書かなかった  |
| 飲む            | 飲まない       | 飲まなかった  |
| 買う            | 買わない       | 買わなかった  |
| 帰る            | 帰らない       | 帰らなかった  |
| 行く            | 行かない       | 行かなかった  |
| 待つ            | 待たない       | 待たなかった  |

The special affirmative past 行く => 行った does not affect its negative conjugation.

## 4. Ichidan Verbs

Remove the final る, add ない, and change ない to なかった.

| Dictionary Form | Plain Negative | Past Negative |
| --------------- | -------------- | ------------- |
| 食べる          | 食べない       | 食べなかった  |
| 見る            | 見ない         | 見なかった    |
| 起きる          | 起きない       | 起きなかった  |
| いる            | いない         | いなかった    |

Remember: not every verb ending in る is Ichidan.

- 帰る => 帰らなかった (Godan)
- 食べる => 食べなかった (Ichidan)

## 5. Irregular and Special Forms

Irregular verbs:

- する => しない => しなかった
- 来る（くる）=> 来ない（こない）=> 来なかった（こなかった）

Special negative form of ある:

- ある => ない => なかった

ある is Godan, but its plain negative is ない rather than あらない.

Compare existence verbs:

- いる => いなかった (Ichidan; animate existence)
- ある => なかった (Godan; inanimate existence)

## 6. Polite vs. Plain Past Negative

| Dictionary Form | Polite Past Negative | Plain Past Negative |
| --------------- | -------------------- | ------------------- |
| 読む            | 読みませんでした     | 読まなかった        |
| 食べる          | 食べませんでした     | 食べなかった        |
| 行く            | 行きませんでした     | 行かなかった        |
| 来る            | 来ませんでした       | 来なかった          |
| する            | しませんでした       | しなかった          |
| ある            | ありませんでした     | なかった            |

Politeness changes, but past negative meaning is preserved.

## 7. Noun vs. Verb Past Negative

| Predicate Type | Plain Non-past Negative | Plain Past Negative |
| -------------- | ----------------------- | ------------------- |
| Noun           | 先生じゃない            | 先生じゃなかった    |
| Verb           | 読まない                | 読まなかった        |

A noun uses its own negative predicate construction.

- 先生ではありませんでした = was not a teacher (polite)
- 先生じゃなかった = was not a teacher (plain)
- 読みませんでした = did not read (polite)
- 読まなかった = did not read (plain)

Do not attach verb endings directly to nouns.

## 8. Example Sentences

昨日、友達は駅に来なかった。= My friend did not come to the station yesterday.

私は今朝、家でコーヒーを飲まなかった。= I did not drink coffee at home this morning.

先生の猫は昨日、家にいなかった。= The teacher's cat was not at home yesterday.

昨日、家に本がなかった。= There was no book at home yesterday.

私は本を買わなかったけど、友達は買った。= I did not buy a book, but my friend did.

あの人は先生じゃなかったけど、日本語を勉強した。= That person was not a teacher but studied Japanese.

## 9. Important Concepts

- ～なかった expresses plain past negation.
- Form it from the plain negative ～ない, not the affirmative past ～た.
- Godan verbs retain their negative A-row stem.
- Ichidan verbs drop る before adding なかった.
- する and 来る use their irregular negative stems.
- ある => ない => なかった is a special case.
- いる is Ichidan; ある is Godan.
- Noun past negatives and verb past negatives have different structures.
- Politeness, tense, and polarity are separate grammatical dimensions.

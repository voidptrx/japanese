# Lesson 053 — Permission with ～てもいいです

## 1. Permission

Use ～てもいいです to indicate that an action is permitted or acceptable.

**Pattern:** Verb て-form + も + いいです

- ～てもいいです = may do; it is okay to do
- ～てもいいですか = may I do ...?; is it okay to do ...?

This expresses permission, not physical ability.

## 2. Formation

Keep the verb's original ～て / ～で form before adding も.

| Dictionary Form | Permission Form  |
| --------------- | ---------------- |
| 食べる          | 食べてもいいです |
| 買う            | 買ってもいいです |
| 読む            | 読んでもいいです |
| 飲む            | 飲んでもいいです |
| 来る            | 来てもいいです   |
| する            | してもいいです   |

**Examples:**

- ここで水を飲んでもいいですか。
  = May I drink water here?

- この部屋で勉強してもいいです。
  = You may study in this room.

## 3. Meaning of ～ても

Verb ～て + も can convey the idea of "even if one does ...".

- 読んでも = even if one reads
- 読んでもいい = it is okay to read

The entire ～てもいい construction expresses permission or acceptability.

**Compare:**

- 友達も = my friend too
- 読んでも = even if one reads

The two uses of も occur in different structures.

## 4. Requests vs. Permission

| Form               | Function              |
| ------------------ | --------------------- |
| 話してください     | Please speak          |
| 話してもいいですか | May I speak?          |
| 話してもいいです   | Speaking is permitted |
| 話しています       | Am/is speaking        |

～てください requests an action from the listener.
～てもいいですか asks whether an action is permitted.

## 5. Connected Actions

A permission question can cover multiple connected actions.

明日、学校に来て、先生と話してもいいですか。
= May I come to school tomorrow and speak with the teacher?

The final ～てもいいですか applies to the connected action sequence.

## 6. Responding to Permission Requests

- はい、いいですよ。= Yes, that's fine.
- はい、読んでもいいです。= Yes, you may read it.

An indirect refusal may explain why permission cannot be granted:

- すみません。今使っています。
  = Sorry. I'm using it now.

## 7. Important Concepts

- Use the verb's ～て / ～で form before もいい.
- ～てもいいです expresses permission or acceptability.
- Adding か turns it into a permission question.
- Permission is different from ability.
- ～てください and ～てもいいですか have different functions.
- The same も particle can have different uses depending on its construction.

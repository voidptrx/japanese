# Lesson 054 — Prohibition with ～てはいけません

## 1. Prohibition

Use ～てはいけません to express that an action is prohibited or unacceptable.

**Pattern:** Verb て-form + は + いけません

- ここで食べてはいけません。= Eating here is prohibited.
- この部屋で電話を使ってはいけません。= You must not use a phone in this room.

The particle は is pronounced _wa_.

## 2. Formation

Keep the verb's ～て / ～で form before adding はいけません.

| Dictionary Form | Prohibition Form   |
| --------------- | ------------------ |
| 食べる          | 食べてはいけません |
| 買う            | 買ってはいけません |
| 読む            | 読んではいけません |
| 飲む            | 飲んではいけません |
| 話す            | 話してはいけません |
| 来る            | 来てはいけません   |
| する            | してはいけません   |

Do not omit は or change ～で into ～て.

## 3. Meaning of ～ては

Verb ～て + は presents the action as something being evaluated.

- 読んではいけません = Reading is not allowed.
- 飲んではいけません = Drinking is not allowed.

The entire ～てはいけません construction expresses prohibition. は alone does not mean "prohibited".

## 4. Permission vs. Prohibition

| Form               | Function              |
| ------------------ | --------------------- |
| 読んでもいいです   | Reading is permitted  |
| 読んでもいいですか | May I read?           |
| 読んではいけません | Reading is prohibited |

**Compare:**

- ここで話してもいいです。= You may speak here.
- ここで話してはいけません。= You must not speak here.

Permission and prohibition are different from ability or inability.

## 5. Plain and Polite Forms

- ～てはいけません = Polite prohibition
- ～てはいけない = Plain prohibition

**Examples:**

- ここで遊んではいけません。
- ここで遊んではいけない。

The alternative ～てはだめ also expresses that an action is not allowed.

## 6. Requests, Permission, and Prohibition

| Form               | Function           |
| ------------------ | ------------------ |
| 待っています       | Ongoing action     |
| 待ってください     | Polite request     |
| 待ってもいいですか | Permission request |
| 待ってはいけません | Prohibition        |

Requests and prohibitions can be contrasted using separate sentences:

この本を読んでください。でも、このノートに書いてはいけません。
= Please read this book. However, do not write in this notebook.

## 7. Important Concepts

- Build the construction from the verb's ～て / ～で form.
- は is required in ～てはいけません.
- ～てはいけません is polite; ～てはいけない is plain.
- ～てもいい expresses permission; ～てはいけない expresses prohibition.
- Prohibition is different from inability.
- Particles such as で, に, を, and と retain their usual functions.

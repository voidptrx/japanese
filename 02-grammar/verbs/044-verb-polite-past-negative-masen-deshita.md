# Lesson 044 — Polite Past Negative Verb Form (～ませんでした)

## 1. Polite Past Negative (～ませんでした)

The ～ませんでした form expresses polite, past-tense negation.

| Non-Past Negative | Past Negative    |
| ----------------- | ---------------- |
| 読みません        | 読みませんでした |
| 書きません        | 書きませんでした |
| 食べません        | 食べませんでした |
| 来ません          | 来ませんでした   |

- 読みません = does not / will not read
- 読みませんでした = did not read

Both forms are polite and negative. Their difference is tense.

## 2. Formation

Use the same ます-stem followed by ませんでした.

読む => 読み

- 読み + ます => 読みます
- 読み + ません => 読みません
- 読み + ました => 読みました
- 読み + ませんでした => 読みませんでした

### Godan (五段動詞)

- 読む => 読みませんでした
- 書く => 書きませんでした
- 行く => 行きませんでした

### Ichidan (一段動詞)

- 食べる => 食べませんでした
- 見る => 見ませんでした

### Irregular Verbs

- する => しませんでした
- 来る（くる）=> 来ませんでした（きませんでした）

## 3. Four Basic Polite Verb Forms

|          | Affirmative | Negative         |
| -------- | ----------- | ---------------- |
| Non-past | 読みます    | 読みません       |
| Past     | 読みました  | 読みませんでした |

All four forms use the same ます-stem.

Tense and polarity are expressed by the ending.

## 4. Past Affirmative vs. Past Negative

- 来ました = came
- 来ませんでした = did not come
- 行きました = went
- 行きませんでした = did not go

Verb meaning, tense, and polarity must be distinguished separately.

## 5. Example Sentences

先生は学校で本を読みませんでした。= The teacher did not read a book at school.

この人は学校に来ませんでした。= This person did not come to school.

あの先生の友達は学校に行きましたが、本を読みませんでした。= That teacher's friend went to school but did not read a book.

どの先生の友達が学校に来ませんでしたか。= Which teacher's friend did not come to school?

## 6. Important Concepts

- ～ませんでした is polite, negative, and past.
- Use the existing ます-stem.
- The four polite verb forms differ in tense and polarity.
- Particles retain their usual functions.
- ～ません and ～ませんでした are not interchangeable.
- Past negative verbs can form polite questions with か.

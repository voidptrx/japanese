# Lesson 047 — Plain Negative Verb Form (～ない)

## 1. Plain Negative Verb Form

The ～ない form expresses plain non-past negation.

- 読みません => 読まない = do not read
- 食べません => 食べない = do not eat
- 来ません => 来ない = do not come

The non-past form can express present habits or future actions depending on context. An ongoing action specifically in progress uses a different construction.

## 2. Godan Verbs

Change the final kana to its A-row equivalent and add ない.

| Ending | Negative Ending |
| ------ | --------------- |
| う     | わない          |
| く     | かない          |
| ぐ     | がない          |
| す     | さない          |
| つ     | たない          |
| ぬ     | なない          |
| ぶ     | ばない          |
| む     | まない          |
| る     | らない          |

Examples:

- 読む => 読まない = do not read
- 書く => 書かない = do not write
- 飲む => 飲まない = do not drink
- 行く => 行かない = do not go
- 買う => 買わない = do not buy
- 帰る => 帰らない = do not return

The う ending changes to わ before ない.

Not every verb ending in る is Ichidan. 帰る is Godan.

## 3. Ichidan Verbs

Remove the final る and add ない.

- 食べる => 食べない
- 見る => 見ない
- 起きる => 起きない
- いる => いない

Example:

部屋に猫がいない。= There is no cat in the room.

## 4. Irregular and Special Forms

Two irregular verbs:

- する => しない
- 来る（くる）=> 来ない（こない）

Special negative form:

- ある => ない

ある is a Godan verb, but its plain negative form is ない, not あらない.

Compare:

- 猫がいる => 猫がいない
- 本がある => 本がない

## 5. Polite vs. Plain Negative

| Dictionary Form | Polite Negative | Plain Negative |
| --------------- | --------------- | -------------- |
| 読む            | 読みません      | 読まない       |
| 食べる          | 食べません      | 食べない       |
| 行く            | 行きません      | 行かない       |
| する            | しません        | しない         |
| 来る            | 来ません        | 来ない         |

Use the verb's dictionary form and group to determine its plain negative conjugation.

## 6. Noun vs. Verb Negation

Noun predicates and verbs form negatives differently.

| Predicate Type | Plain Affirmative | Plain Negative |
| -------------- | ----------------- | -------------- |
| Noun           | 先生だ            | 先生じゃない   |
| Verb           | 読む              | 読まない       |

A negative verb already forms a complete predicate. Do not add だ or じゃない after it.

## 7. Example Sentences

この人は水を飲まない。= This person does not drink water.

どの日本人が明日学校に来ない？ = Which Japanese person will not come to school tomorrow?

先生の猫は部屋にいない。= The teacher's cat is not in the room.

この人は本を買わないけど、家で本を読む。= This person does not buy books but reads books at home.

## 8. Important Concepts

- ～ない is the plain non-past negative verb form.
- Godan verbs change their final kana before adding ない.
- Ichidan verbs drop る before adding ない.
- する and 来る have irregular negative forms.
- ある is Godan but has the special negative ない.
- Verb negatives differ from noun negatives.
- Plain past negative verbs will be studied separately.

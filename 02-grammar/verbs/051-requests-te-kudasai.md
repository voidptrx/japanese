# Lesson 051 — Requests with ～てください

## 1. Polite Requests

Use the verb's ～て form followed by ください to request an action politely.

**Pattern:** Verb て-form + ください

**Examples:**

- 待つ → 待ってください = Please wait.
- 読む → 読んでください = Please read.
- 書く → 書いてください = Please write.
- 来る → 来てください = Please come.
- する → してください = Please do.

Do not attach ください directly to the dictionary or ます form.

## 2. Requesting Objects vs. Actions

ください can request an object or an action.

- この本をください。= Please give me this book.
- この本を読んでください。= Please read this book.

The first requests an object. The second requests an action using the ～て form.

## 3. Requests and Tense

～てください expresses a request, not a past or non-past statement.

**Compare:**

- 本を読みます。= I read / will read a book.
- 本を読みました。= I read a book (past).
- 本を読んでください。= Please read a book.

The requested action is normally to be performed by the listener.

## 4. Connected Actions

Multiple actions can be connected with ～て, with ください attached to the final verb.

学校に行って、先生と話してください。= Please go to school and speak with the teacher.

The request applies to both actions.

## 5. Particles in Requests

Particles retain their usual functions.

- 駅で待ってください。= Please wait at the station.
- 友達と日本語で話してください。= Please speak Japanese with your friend.
- ノートに名前を書いてください。= Please write your name in the notebook.

## 6. Important Concepts

- ～てください makes a polite but direct request.
- It requests an action rather than reporting an event.
- Object + を + ください requests an object.
- Verb て-form + ください requests an action.
- Connected actions can share one final ください.
- Grammatically polite requests are not necessarily appropriate in every social situation.

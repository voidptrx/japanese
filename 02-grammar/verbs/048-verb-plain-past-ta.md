# Lesson 048 — Plain Past Verb Form (～た)

## 1. Plain Past Verb Form

The ～た form expresses plain past affirmative actions or events.

Examples:

- 読みました => 読んだ = read (past)
- 食べました => 食べた = ate
- 行きました => 行った = went

Some Godan verbs end in だ rather than た because of sound changes.

## 2. Godan Verbs

Godan verbs follow five main ending patterns.

| Dictionary Ending | Past Ending | Example        |
| ----------------- | ----------- | -------------- |
| う・つ・る        | った        | 買う => 買った |
| む・ぶ・ぬ        | んだ        | 読む => 読んだ |
| く                | いた        | 書く => 書いた |
| ぐ                | いだ        | 泳ぐ => 泳いだ |
| す                | した        | 話す => 話した |

Additional examples:

- 待つ => 待った = waited
- 帰る => 帰った = returned
- 飲む => 飲んだ = drank

The transformation depends on the dictionary-form ending.

## 3. Important Exception: 行く

行く is a Godan verb, but its plain past form is irregular.

- 書く => 書いた (regular く pattern)
- 行く => 行った (exception)

Do not use 行いた for the basic past form of 行く.

## 4. Ichidan Verbs

Remove the final る and add た.

- 食べる => 食べた
- 見る => 見た
- 起きる => 起きた
- いる => いた

A verb ending in る is not necessarily Ichidan.

**Compare:**

- 帰る => 帰った (Godan)
- 食べる => 食べた (Ichidan)

## 5. Irregular and Special Verbs

- する => した
- 来る（くる）=> 来た（きた）

The Godan verb ある follows the regular る => った pattern:

- ある => あった

Its plain negative ない is a separate special form.

## 6. Polite vs. Plain Past

| Dictionary Form | Polite Past | Plain Past |
| --------------- | ----------- | ---------- |
| 読む            | 読みました  | 読んだ     |
| 書く            | 書きました  | 書いた     |
| 食べる          | 食べました  | 食べた     |
| 行く            | 行きました  | 行った     |
| 来る            | 来ました    | 来た       |
| する            | しました    | した       |

Changing politeness does not change the past affirmative meaning.

## 7. Noun vs. Verb Past Forms

| Predicate Type | Non-past Plain | Past Plain |
| -------------- | -------------- | ---------- |
| Noun           | 先生だ         | 先生だった |
| Verb           | 読む           | 読んだ     |

先生だった is a past noun predicate.

読んだ is a conjugated verb. Its final だ is not the independent noun-predicate だ.

## 8. Example Sentences

今日、友達は駅に来た。= My friend came to the station today.

私は友達と公園に行った。= I went to the park with my friend.

友達は公園でパンを食べた。= My friend ate bread at the park.

昨日、私は駅で友達を待った。= Yesterday, I waited for my friend at the station.

私は家に帰ったけど、友達は公園で本を読んだ。= I returned home, but my friend read a book at the park.

## 9. Important Concepts

- ～た is the plain past affirmative verb form.
- Godan past forms involve ending-dependent sound changes.
- 行く => 行った is an important exception.
- Ichidan verbs drop る and add た.
- する => した and 来る => 来た are irregular.
- Noun-predicate だった and verb past forms are structurally different.
- Plain past negative verbs will be studied separately.

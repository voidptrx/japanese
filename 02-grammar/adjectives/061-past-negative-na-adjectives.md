# Lesson 061 — Past Negative な-Adjectives (～じゃなかった)

## 1. Formation

な-adjectives form the plain past negative by changing じゃない to じゃなかった.

**Pattern:** な-adjective + じゃなかった

| Non-Past Negative | Past Negative      |
| ----------------- | ------------------ |
| 静かじゃない      | 静かじゃなかった   |
| 元気じゃない      | 元気じゃなかった   |
| きれいじゃない    | きれいじゃなかった |
| 親切じゃない      | 親切じゃなかった   |
| 丈夫じゃない      | 丈夫じゃなかった   |

- 昨日、公園は静かじゃなかった。= The park was not quiet yesterday.
- 友達は元気じゃなかった。= My friend was not well.

## 2. Plain and Polite Past Negative

| Form                   | Example                  | Register            |
| ---------------------- | ------------------------ | ------------------- |
| ～じゃなかった         | 静かじゃなかった         | Plain               |
| ～じゃなかったです     | 静かじゃなかったです     | Polite              |
| ～ではありませんでした | 静かではありませんでした | Polite; more formal |

All three express the same past negative meaning.

Another valid polite form is ～ではなかったです.

Incorrect: 静かじゃないでした, 静かじゃなかったでした

## 3. Four Basic な-Adjective Forms

| Tense    | Positive   | Negative         |
| -------- | ---------- | ---------------- |
| Non-past | 静かだ     | 静かじゃない     |
| Past     | 静かだった | 静かじゃなかった |

Polite equivalents:

| Tense    | Positive   | Negative             |
| -------- | ---------- | -------------------- |
| Non-past | 静かです   | 静かじゃないです     |
| Past     | 静かでした | 静かじゃなかったです |

The more formal negative forms use ではありません and ではありませんでした.

## 4. Comparison with Nouns and い-Adjectives

| Type         | Plain Past Negative | Polite Past Negative |
| ------------ | ------------------- | -------------------- |
| Noun         | 学生じゃなかった    | 学生じゃなかったです |
| な-adjective | 元気じゃなかった    | 元気じゃなかったです |
| い-adjective | 寒くなかった        | 寒くなかったです     |

Noun predicates and な-adjectives share similar negative endings.

い-adjectives use ～くなかった instead.

- きれい → きれいじゃなかった
- 可愛い → 可愛くなかった

Incorrect: きれくなかった, 静かくなかった

## 5. Modifying Nouns

A past negative な-adjective can modify a noun directly.

| Structure            | Meaning                 |
| -------------------- | ----------------------- |
| 静かな部屋           | quiet room              |
| 静かじゃない部屋     | room that is not quiet  |
| 静かだった部屋       | room that was quiet     |
| 静かじゃなかった部屋 | room that was not quiet |

Do not add な after じゃなかった.

Incorrect: 静かじゃなかったな部屋

**Example:**

昨日、静かじゃなかった部屋で本を読まなかった。
= Yesterday, I did not read a book in a room that was not quiet.

静かじゃなかった modifies 部屋; 読まなかった is the main predicate.

## 6. Past and Non-Past Contrast

- 昨日、友達は元気じゃなかった。
  = My friend was not well yesterday.

- 今日は元気だ。
  = My friend is well today (in context).

Combined:

昨日、友達は元気じゃなかったけど、今日は元気だ。
= My friend was not well yesterday, but is well today.

Keep tense and polarity consistent with each intended meaning.

## 7. Polite Connections and Register

For polite contrastive sentences:

- 丈夫じゃなかったですけど、高くなかったです。
  = It was not sturdy, but it was not expensive.

More formal:

- 丈夫ではありませんでしたが、高くありませんでした。
  = It was not sturdy, but it was not expensive.

Avoid mixing registers without a reason.

The combination ～じゃなかったですが is understandable but generally less natural than the alternatives above.

## 8. Important Concepts

- Plain past negative: ～じゃなかった.
- Polite past negative: ～じゃなかったです.
- More formal polite past negative: ～ではありませんでした.
- な-adjectives and nouns share similar negative predicate forms.
- い-adjectives use ～くなかった instead.
- Past negative な-adjectives modify nouns without an additional な.
- Distinguish adjective modification from the main predicate.
- The four basic な-adjective forms are now complete.

# Lesson 059 — Negative な-Adjectives (～じゃない)

## 1. Formation

な-adjectives form their negative predicates similarly to nouns.

**Pattern:** な-adjective + じゃない

| Positive | Negative       |
| -------- | -------------- |
| 静かだ   | 静かじゃない   |
| 元気だ   | 元気じゃない   |
| きれいだ | きれいじゃない |
| 親切だ   | 親切じゃない   |
| 丈夫だ   | 丈夫じゃない   |

- この部屋は静かじゃない。= This room is not quiet.
- 友達は元気じゃない。= My friend is not well.

The adjective stem remains unchanged.

## 2. Plain and Polite Negative Forms

| Form             | Example            | Register            |
| ---------------- | ------------------ | ------------------- |
| ～じゃない       | 静かじゃない       | Plain               |
| ～じゃないです   | 静かじゃないです   | Polite              |
| ～ではありません | 静かではありません | Polite; more formal |

All three express non-past negative meaning.

- 静かじゃないです = not quiet (polite)
- 静かではありません = not quiet (more formal)

じゃ is a contraction of では.

Other valid forms include ～ではない and ～じゃありません.

## 3. な-Adjectives vs. い-Adjectives

The two adjective types use different negative forms.

| Type         | Positive | Negative     |
| ------------ | -------- | ------------ |
| い-adjective | 寒い     | 寒くない     |
| な-adjective | 静かだ   | 静かじゃない |

The adjective きれい ends in い but is a な-adjective.

- きれい → きれいじゃない
- 可愛い → 可愛くない

Incorrect: きれくない, きれいくない, 静かくない

## 4. Connection to Noun Predicates

な-adjective negation resembles noun predicate negation.

| Type         | Positive | Negative     |
| ------------ | -------- | ------------ |
| Noun         | 学生だ   | 学生じゃない |
| な-adjective | 元気だ   | 元気じゃない |

However, な-adjectives use な when modifying nouns in their basic positive form.

- 静かな部屋 = quiet room
- 学生の友達 = student friend / friend's student (context-dependent)

## 5. Modifying Nouns

Positive な-adjectives use な before a noun.

Negative な-adjective forms modify nouns directly without an additional な.

| Positive     | Negative           |
| ------------ | ------------------ |
| 静かな部屋   | 静かじゃない部屋   |
| 元気な友達   | 元気じゃない友達   |
| きれいな部屋 | きれいじゃない部屋 |

Incorrect: 静かじゃないな部屋

**Example:**

友達は静かじゃない部屋で本を読んでいる。
= My friend is reading a book in a room that is not quiet.

The negative adjective modifies 部屋; 読んでいる is the main predicate.

## 6. Meaning and Polarity

Negative adjectives do not necessarily imply their opposites.

- 静かじゃない = not quiet; not necessarily extremely noisy
- 元気じゃない = not well or not energetic
- きれいじゃない = not clean or not beautiful

Preserve the negative meaning when translating.

## 7. Predicate vs. Noun Modification

- 静かな部屋 = quiet room
- 静かじゃない部屋 = room that is not quiet
- この部屋は静かじゃない。= This room is not quiet.

The first two modify nouns. The third uses a negative adjective predicate.

## 8. Important Concepts

- な-adjective negative: ～じゃない.
- ～じゃない is plain; ～じゃないです is polite.
- ～ではありません is a more formal polite alternative.
- きれい is a な-adjective despite ending in い.
- Negative な-adjectives modify nouns without an additional な.
- Keep the tense of the main predicate separate from adjective modification.
- Past and past negative な-adjectives are covered in later lessons.

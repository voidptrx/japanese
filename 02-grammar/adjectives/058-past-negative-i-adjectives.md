# Lesson 058 — Past Negative い-Adjectives (～くなかった)

## 1. Formation

To form the past negative of an い-adjective, remove the final い and add くなかった.

**Pattern:** い-adjective stem + くなかった

Alternatively, form the non-past negative first, then change ない to なかった.

高い → 高くない → 高くなかった

| Positive | Past Negative    |
| -------- | ---------------- |
| 高い     | 高くなかった     |
| 面白い   | 面白くなかった   |
| 暑い     | 暑くなかった     |
| 寒い     | 寒くなかった     |
| 可愛い   | 可愛くなかった   |
| おいしい | おいしくなかった |
| 涼しい   | 涼しくなかった   |

- 昨日は暑くなかった。= It was not hot yesterday.
- あの本は面白くなかった。= That book was not interesting.

## 2. Plain and Polite Past Negative

| Form                 | Example              | Register            |
| -------------------- | -------------------- | ------------------- |
| ～くなかった         | 高くなかった         | Plain               |
| ～くなかったです     | 高くなかったです     | Polite              |
| ～くありませんでした | 高くありませんでした | Polite; more formal |

All three express the same past negative meaning.

- 高くなかったです = was not expensive (polite)
- 高くありませんでした = was not expensive (more formal)

Structural difference:

- ～くなかったです: past negative adjective + です
- ～くありませんでした: adjective ～く form + ありませんでした

Incorrect: 高くないでした, 高くなかったでした, 高くなかっただ

## 3. Exception: いい

The adjective いい uses the older よい stem when conjugated.

| Form              | Example      |
| ----------------- | ------------ |
| Non-past positive | いい         |
| Non-past negative | よくない     |
| Past positive     | よかった     |
| Past negative     | よくなかった |

- 昨日の天気はよくなかった。= Yesterday's weather was not good.
- 昨日の天気はよくありませんでした。= Yesterday's weather was not good (more formal).

Incorrect: いくなかった, いいくなかった

## 4. Four Basic い-Adjective Forms

| Tense    | Positive | Negative     |
| -------- | -------- | ------------ |
| Non-past | 高い     | 高くない     |
| Past     | 高かった | 高くなかった |

- 高い = expensive
- 高くない = not expensive
- 高かった = was expensive
- 高くなかった = was not expensive

The same pattern applies to regular い-adjectives.

## 5. Modifying Nouns

Past negative い-adjectives can directly modify nouns.

- 面白くない本 = a book that is not interesting
- 面白くなかった本 = a book that was not interesting

Do not insert な before the noun.

Distinguish the tense of a modifying adjective from the tense of the main predicate.

- 昨日、面白くない本を読んだ。
  = Yesterday, I read an uninteresting book.
- 昨日、面白くなかった本を読んだ。
  = Yesterday, I read a book that was not interesting.

## 6. Adjective vs. Verb Past Negative

| Type         | Non-past Negative | Past Negative  |
| ------------ | ----------------- | -------------- |
| い-adjective | 面白くない        | 面白くなかった |
| Verb         | 読まない          | 読まなかった   |

- 読まなかった = did not read
- 面白くなかった = was not interesting

Incorrect: 読んだない

Do not use adjective conjugation rules for verbs or verb conjugation rules for adjectives.

## 7. Meaning and Time

A negative adjective does not necessarily imply the opposite quality.

- 寒くなかった = was not cold; not necessarily warm
- 高くなかった = was not expensive; not necessarily cheap
- おいしくなかった = was not tasty; not necessarily terrible

Time expressions do not automatically change predicate tense.

- 昨日は寒くなかった。= It was not cold yesterday.
- 今日は寒くない。= It is not cold today.

Keep each predicate's tense and polarity consistent with the intended meaning.

## 8. Important Concepts

- Replace the final い with くなかった.
- ない changes to なかった in the past negative.
- いい is irregular: よくなかった.
- ～くなかった is plain; ～くなかったです is polite.
- ～くありませんでした is a more formal polite alternative.
- Past negative い-adjectives can modify nouns directly.
- Distinguish adjective tense from the tense of the main verb.
- The four basic い-adjective forms are now complete.

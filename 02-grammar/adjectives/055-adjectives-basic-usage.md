# Lesson 055 — Introduction to い-Adjectives and な-Adjectives

## 1. Adjective Classes

Japanese has two main adjective classes:

- い-adjectives: 面白い, 高い, 可愛い
- な-adjectives: 静か, 元気, 親切

Both can modify nouns and serve as predicates, but their grammar differs.

## 2. Modifying Nouns

**い-adjective + noun**

- 面白い本 = interesting book
- 可愛い犬 = cute dog

**な-adjective + な + noun**

- 静かな部屋 = quiet room
- 親切な人 = kind person

Do not insert な or の between an い-adjective and its noun.

## 3. Adjectives as Predicates

| Class        | Plain  | Polite     |
| ------------ | ------ | ---------- |
| い-adjective | 面白い | 面白いです |
| な-adjective | 静かだ | 静かです   |

- この本は面白い。= This book is interesting.
- この部屋は静かだ。= This room is quiet.

い-adjectives can directly form predicates. Never add declarative だ to them.

な-adjectives behave similarly to nouns in affirmative plain predicates. Do not add な before だ or です.

## 4. Important Exceptions

Not every adjective ending in い is an い-adjective.

- きれい = な-adjective
- きれいな部屋 = beautiful / clean room
- この部屋はきれいです。= This room is beautiful / clean.

Learn an adjective's class with the word.

## 5. Comparison with Nouns

| Type         | Noun Modification | Plain Predicate    |
| ------------ | ----------------- | ------------------ |
| Noun         | 日本語の本        | これは本だ。       |
| い-adjective | 面白い本          | この本は面白い。   |
| な-adjective | 静かな部屋        | この部屋は静かだ。 |

## 6. Degree

とても can modify both adjective classes.

- とても高い = very expensive
- とても静か = very quiet

Negative and past adjective forms are covered in later lessons.

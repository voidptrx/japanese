# Lesson 056 — Negative い-Adjectives (～くない)

## 1. Formation

To make an い-adjective negative, remove the final い and add くない.

**Pattern:** い-adjective stem + くない

| Positive | Negative     |
| -------- | ------------ |
| 高い     | 高くない     |
| 面白い   | 面白くない   |
| 暑い     | 暑くない     |
| 寒い     | 寒くない     |
| 可愛い   | 可愛くない   |
| おいしい | おいしくない |

- このコーヒーは高くない。= This coffee is not expensive.
- 今日は寒くない。= It is not cold today.

Only the final い changes: 可愛い → 可愛くない.

## 2. Plain and Polite Negative Forms

| Form           | Example        | Register            |
| -------------- | -------------- | ------------------- |
| ～くない       | 高くない       | Plain               |
| ～くないです   | 高くないです   | Polite              |
| ～くありません | 高くありません | Polite; more formal |

Both polite forms express the same negative meaning.

- 高くないです = not expensive (polite)
- 高くありません = not expensive (polite)

Do not attach だ to negative い-adjectives.

## 3. Exception: いい

The adjective いい (good) uses the older よい stem when conjugated.

- いい → よくない
- いい → よくないです
- いい → よくありません

Incorrect: いいくない, いくない

**Example:**

この本はよくないです。= This book is not good.

## 4. Modifying Nouns

Negative い-adjectives directly modify nouns.

- 面白くない本 = uninteresting book
- 高くないノート = notebook that is not expensive
- 可愛くない犬 = dog that is not cute

Do not insert な or の before the noun.

**Example:**

友達は面白くない本を読んでいます。
= My friend is reading an uninteresting book.

## 5. Negative Meaning

Negating an adjective does not necessarily imply its opposite.

- 暑くない = not hot; not necessarily cold
- 高くない = not expensive; not necessarily cheap
- 涼しくない = not cool; not necessarily hot

Preserve negative meaning when reading and translating.

## 6. Adjective vs. Verb Negation

| Structure             | Example        | Function               |
| --------------------- | -------------- | ---------------------- |
| Negative い-adjective | 寒くない       | Not cold               |
| Negative verb         | 勉強しない     | Do not study           |
| Negative ～ている     | 勉強していない | Not currently studying |

The presence of ない does not turn an adjective into a verb.

**Examples:**

- 今日は寒くない。= It is not cold today.
- 今、日本語を勉強していない。= I am not studying Japanese now.

## 7. Important Concepts

- Change the final い to くない.
- いい is irregular: よくない.
- ～くない is plain; ～くないです and ～くありません are polite.
- Negative い-adjectives can modify nouns directly.
- Do not apply this rule to な-adjectives such as きれい.
- Adjective negation and verb negation are different grammatical structures.
- Past adjective forms are covered in later lessons.

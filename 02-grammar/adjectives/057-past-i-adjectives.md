# Lesson 057 — Past い-Adjectives (～かった)

## 1. Formation

To make an い-adjective past tense, remove the final い and add かった.

**Pattern:** い-adjective stem + かった

| Non-Past | Past         |
| -------- | ------------ |
| 高い     | 高かった     |
| 面白い   | 面白かった   |
| 暑い     | 暑かった     |
| 寒い     | 寒かった     |
| 可愛い   | 可愛かった   |
| おいしい | おいしかった |
| 涼しい   | 涼しかった   |

- 昨日は寒かった。= It was cold yesterday.
- あの本は面白かった。= That book was interesting.

## 2. Plain and Polite Past

| Form         | Example      | Register |
| ------------ | ------------ | -------- |
| ～かった     | 高かった     | Plain    |
| ～かったです | 高かったです | Polite   |

- このコーヒーは高かった。= This coffee was expensive.
- このコーヒーは高かったです。= This coffee was expensive (polite).

Incorrect: 高いでした, 高かっただ

い-adjectives form their own past tense. Do not attach でした directly to the non-past adjective.

## 3. Exception: いい

The adjective いい (good) uses the older よい stem when conjugated.

| Form              | Example  |
| ----------------- | -------- |
| Non-past positive | いい     |
| Non-past negative | よくない |
| Past positive     | よかった |

- 昨日は天気がよかった。= The weather was good yesterday.
- 昨日は天気がよかったです。= The weather was good yesterday (polite).

Incorrect: いかった, いいかった

## 4. Comparing Predicate Types

Nouns, verbs, and い-adjectives have different past forms.

| Predicate Type | Non-Past | Past       |
| -------------- | -------- | ---------- |
| Noun           | 学生だ   | 学生だった |
| Verb           | 読む     | 読んだ     |
| い-adjective   | 高い     | 高かった   |

A past-tense adjective remains an adjective predicate, not a verb.

## 5. Past and Non-Past Contrast

- 昨日は寒かった。= It was cold yesterday.
- 今日は寒くない。= It is not cold today.

Combined:

昨日は寒かったけど、今日は寒くない。
= It was cold yesterday, but it is not cold today.

Keep the tense and polarity of each predicate separate.

## 6. Time Expressions and Noun Modification

Distinguish a time expression modifying a noun from one modifying the sentence.

- 昨日の本 = yesterday's book
- 昨日、本を読んだ。= I read a book yesterday.

**Examples:**

- 昨日の本は面白かった。= Yesterday's book was interesting.
- 昨日、この本を読んだ。= I read this book yesterday.

The particle の connects 昨日 to the following noun.

## 7. Important Concepts

- Replace the final い with かった.
- いい is irregular: よかった.
- ～かった is plain; ～かったです is polite.
- Do not use でした or だ after past い-adjectives.
- Adjective past tense differs from noun and verb past tense.
- Preserve time expressions, demonstratives, and polarity when translating.
- Past negative い-adjectives are covered in Lesson 058.

# Lesson 069 — Basic Time Expressions

## 1. Core Expressions

| Expression | Reading  | Meaning                |
| ---------- | -------- | ---------------------- |
| 今         | いま     | now                    |
| さっき     | さっき   | a moment ago; just now |
| これから   | これから | from now on; about to  |
| 後で       | あとで   | later; afterward       |
| もうすぐ   | もうすぐ | very soon; shortly     |

These expressions indicate time relative to the present or another contextual reference point.

## 2. Basic Usage

- さっき、スーパーでりんごを買った。 — I bought apples at the supermarket a moment ago.
- 今、猫の写真を見ています。 — I am looking at a photo of a cat now.
- これから、新しいゲームをします。 — I am going to play a new game now.
- 後で、ノートに名前を書きます。 — I will write my name in the notebook later.
- もうすぐ、電車が来ます。 — The train will arrive very soon.

さっき commonly refers to recent past events. これから indicates a starting point from now, while もうすぐ emphasizes that an event will occur soon.

後で indicates a later time without specifying exactly when.

## 3. Time and Verb Forms

| Expression             | Typical meaning            |
| ---------------------- | -------------------------- |
| さっき、ゲームをした。 | Played a game a moment ago |
| 今、ゲームをしている。 | Playing a game now         |
| これからゲームをする。 | Going to play a game now   |
| 後でゲームをする。     | Will play a game later     |
| もうすぐ友達が来る。   | A friend will arrive soon  |

Time expressions provide context, while verb forms express tense, polarity, and aspect.

## 4. まだ and Negative ～ている

**まだ～ていない** expresses an action that has not happened yet.

- 借りた本はまだ読んでいない。 — I have not read the borrowed book yet.
- 新しい傘はまだ使っていません。 — I have not used the new umbrella yet.

Compare:

- 読まなかった — did not read
- まだ読んでいない — have not read yet
- 今、読んでいない — am not reading now

Do not replace まだ読んでいない with まだ読まない when the intended meaning is "have not read yet."

## 5. Particles

The main time expressions in this lesson normally do not require temporal に.

- さっき、友達に会いました。
- 後で、先生と話します。
- ８時に家に帰ります。

Specific clock times generally take に. Other particles retain their ordinary functions.

With 出る, both a departure-point expression with から and a place-left expression with を are possible:

- 駅から出る。 — Leave from the station.
- 駅を出る。 — Leave the station.

## 6. Pronunciation

| Word           | Mora               |
| -------------- | ------------------ |
| 今（いま）     | い・ま — 2         |
| さっき         | さ・っ・き — 3     |
| これから       | こ・れ・か・ら — 4 |
| 後で（あとで） | あ・と・で — 3     |
| もうすぐ       | も・う・す・ぐ — 4 |

The small っ in さっき represents a consonant closure and counts as one mora.

## 7. Important Concepts

- Distinguish recent past, present, immediate future, and later events.
- さっき commonly accompanies past-tense predicates.
- これから means starting from now; もうすぐ emphasizes imminent events.
- 後で means later, without a fixed time.
- まだ～ていない means "have not done yet."
- ～ている can express continuing actions or resulting states.
- Preserve tense, polarity, aspect, objects, and locations when translating.
- Maintain the intended plain or polite speech register.

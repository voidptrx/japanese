# Lesson 003 - Hiragana Dakuten & Handakuten

## 1. What I learned

- I learned how dakuten (゛) changes certain hiragana sounds.
- I learned how handakuten (゜) changes the は row.
- I understand these as transformations of existing kana rows rather than completely separate patterns.
- I can recognize dakuten and handakuten kana individually and inside words.

# 2. Dakuten

Dakuten is the mark `゛`. It changes the sound of certain kana.

### The `か` row

| が  | ぎ  | ぐ  | げ  | ご  |
| :-: | :-: | :-: | :-: | :-: |
| ga  | gi  | gu  | ge  | go  |

The vowel pattern stays the same. The consonant changes from `k` to `g`.

### The `さ` row

| ざ  | じ  | ず  | ぜ  | ぞ  |
| :-: | :-: | :-: | :-: | :-: |
| za  | ji  | zu  | ze  | zo  |

> [!IMPORTANT]
> `じ` is read as `ji`.

### The `た` row

| だ  | ぢ  | づ  | で  | ど  |
| :-: | :-: | :-: | :-: | :-: |
| da  | ji  | zu  | de  | do  |

> [!IMPORTANT]
> `ぢ` is read as `ji`.
> `づ` is read as `zu`.

## 3. Handakuten

Handakuten is a small circle `゜`. It is used with the `は` row.

### The `は` row

The handakuten changes the row to the `p`-sound.

| ぱ  | ぴ  | ぷ  | ぺ  | ぽ  |
| :-: | :-: | :-: | :-: | :-: |
| pa  | pi  | pu  | pe  | po  |

## 4. Main transformation patterns

The basic patterns learned in this lesson are:

- k -> g
- s -> z
- t -> d
- h -> b
- h -> p

The vowel pattern `a-i-u-e-o` remains consistent withing each row.

# Lesson 011 - Katakana Sokuon (Small ッ)

## 1. What I learned

- I learned the difference between `ツ` and `ッ`.
- I understand how small `ッ` affects Japanese pronunciation.
- I learned how sokuon is represented in romaji.
- I can count mora in words containing sokuon.
- I can read words containing both sokuon and yoon.

## 2. What is Sokuon?

Sokuon (促音) is represented by the small `ッ`.  
Unlike normal `ツ`, small `ッ` does not produce a separate 'tsu' sound.  
It represents one mora associated with the consonant that follows it.

Examples:

- カト = kato = 2 mora
- カット = katto = 3 mora

## 3. Sokuon and Romaji

Sokuon is commonly represented by doubling the following consonant in romaji.

Examples:

- ッカ = kka
- ッテ = tte
- ッパ = ppa
- ッシ = sshi

The doubled consonant represents a timing difference.

Examples in words:

- カップ = kappu = 3 mora
- バッグ = baggu = 3 mora
- ベッド = beddo = 3 mora
- チケット = chiketto = 4 mora

## 4. Sokuon and Yoon

Sokuon and yoon can appear in the same word.

Example:

ショック = shokku = 3 mora

- ショ = 1 mora
- ッ = 1 mora
- ク = 1 mora

Another example:

キャップ = kyappu = 3 mora

- キャ = 1 mora
- ッ = 1 mora
- プ = 1 mora

Important distinction:

- Small ャ / ュ / ョ does not add a separate mora.
- Small ッ adds one mora.

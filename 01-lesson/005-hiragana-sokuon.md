# Lesson 005 - Hiragana Sokuon (Small っ)

## 1. What I learned

- I learned the difference between `つ` and `っ`.
- I understand how small `っ` affects Japanese pronunciation.
- I learned how sokuon is represented in romaji.
- I can count mora in words containing sokuon.
- I can read words conatining both sokuon and yoon.

## 2. What is Sokuon?

Sokuon (促音) is represented by the small `っ`.  
Unlike normal `つ`, small `っ` does not produce a separate 'tsu' sound.  
It represents one mora associated with the consonant that follows it.

Examples:

- きて = kite = 2 mora
- きって = kitte = 3 mora

## 3. Sokuon and Romaji

Sokuon is commonly represented by doubling the following consonant in romaji.

Examples:

- っか = kka
- って = tte
- っぱ = ppa
- っし = sshi

The doubled consonant represents a timing difference.

## 4. Sokuon and Yoon

Sokuon and yoon can appear in the same word.

Example:

ちょっと = chotto = 3 mora

- ちょ = 1 mora
- っ = 1 mora
- と = 1 mora

Another example:

いっしょ = issho = 3 mora

- い = 1 mora
- っ = 1 mora
- しょ = 1 mora

Important distinction:

- Small ゃ / ゅ / ょ does not add a separate mora.
- Small っ adds one mora.

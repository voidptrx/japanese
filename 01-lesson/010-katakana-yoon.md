# Lesson 010 - Katakana Yoon (Small ャ / ュ / ョ)

## 1. What I learned

- I learned how small ャ, ュ and ョ combine with other katakana.
- I understand the difference between small and full-sized kana.
- I learned how yoon combinations affect mora counting.
- I can recognize basic yoon combinations, including dakuten and handakuten forms.

## 2. What is Yoon?

Yoon (ようおん / 拗音) is a combination of an i-column kana and a small ャ, ュ or ョ.

Examples:

- キャ = kya
- キュ = kyu
- キョ = kyo

Each combination represents one mora.

## 3. Small vs. Full-Sized Kana

- キャ = kya = 1 mora
- キヤ = kiya = 2 mora

- キュ = kyu = 1 mora
- キユ = kiyu = 2 mora

- キョ = kyo = 1 mora
- キヨ = kiyo = 2 mora

Small ャ / ュ / ョ changes the reading and mora count.

## 4. Basic Yoon Combinations

| Base | ャ         | ュ         | ョ         |
| ---- | ---------- | ---------- | ---------- |
| キ   | キャ (kya) | キュ (kyu) | キョ (kyo) |
| シ   | シャ (sha) | シュ (shu) | ショ (sho) |
| チ   | チャ (cha) | チュ (chu) | チョ (cho) |
| ニ   | ニャ (nya) | ニュ (nyu) | ニョ (nyo) |
| ヒ   | ヒャ (hya) | ヒュ (hyu) | ヒョ (hyo) |
| ミ   | ミャ (mya) | ミュ (myu) | ミョ (myo) |
| リ   | リャ (rya) | リュ (ryu) | リョ (ryo) |

> [!IMPORTANT]
> シャ = sha, not shya.
> チャ = cha, not chya.

## 5. Dakuten and Handakuten with Yoon

| Base | ャ         | ュ         | ョ         |
| ---- | ---------- | ---------- | ---------- |
| ギ   | ギャ (gya) | ギュ (gyu) | ギョ (gyo) |
| ジ   | ジャ (ja)  | ジュ (ju)  | ジョ (jo)  |
| ビ   | ビャ (bya) | ビュ (byu) | ビョ (byo) |
| ピ   | ピャ (pya) | ピュ (pyu) | ピョ (pyo) |

Dakuten and handakuten do not change the one-mora rule for yoon combinations.

## 6. Important Concepts

- Yoon: A contracted sound formed with small ャ / ュ / ョ.
- A yoon combination counts as one mora.
- Full-sized ヤ / ユ / ヨ is pronounced separately.
- ン counts as one mora even when it appears after a yoon combination.
- Katakana yoon follows the same mora rules as hiragana yoon.

# Lesson 004 - Hiragana Yoon (Small ゃ / ゅ / ょ)

## 1. What I learned

- I learned how small ゃ, ゅ and ょ combine with other hiragana.
- I understand the difference between small and full-sized kana.
- I Learned how yoon combinations affect mora counting.
  I can recognize basic yoon conbinations, including dakuten and handakuten forms.

## 2. What is Yoon?

Yoon (ようおん / 拗音) is a combination of an i-column kana and a small ゃ, ゅ or ょ.

Examples:

- きゃ = kya
- きゅ = kyu
- きょ = kyo

Each combinations represents one mora.

## 3. Small vs. Full-Sized Kana

- きゃ = kya = 1 mora
- きや = kiya = 2 mora

- きゅ = kyu = 1 mora
- きゆ = kiyu = 2 mora

Small ゃ / ゅ / ょ changes the reading and mora count.

## 4. Basic Yoon Combinations

| Base | ゃ         | ゅ         | ょ         |
| ---- | ---------- | ---------- | ---------- |
| き   | きゃ (kya) | きゅ (kyu) | きょ (kyo) |
| し   | しゃ (sha) | しゅ (shu) | しょ (sho) |
| ち   | ちゃ (cha) | ちゅ (chu) | ちょ (cho) |
| に   | にゃ (nya) | にゅ (nyu) | にょ (nyo) |
| ひ   | ひゃ (hya) | ひゅ (hyu) | ひょ (hyo) |
| み   | みゃ (mya) | みゅ (myu) | みょ (myo) |
| り   | りゃ (rya) | りゅ (ryu) | りょ (ryo) |

> [!IMPORTANTANT]
> しゃ = sha, not shya  
> ちゃ = cha, not chya

## 5. Dakuten and Handakuten with Yoon

| Base | ゃ         | ゅ         | ょ         |
| ---- | ---------- | ---------- | ---------- |
| ぎ   | ぎゃ (gya) | ぎゅ (gyu) | ぎょ (gyo) |
| じ   | じゃ (ja)  | じゅ (ju)  | じょ (jo)  |
| び   | びゃ (bya) | びゅ (byu) | びょ (byo) |
| ぴ   | ぴゃ (pya) | ぴゅ (pyu) | ぴょ (pyo) |

Dakuten and handakuten do not change the one-mora rule for yoon combinations.

## 6. Important Concepts

- Yoon: A contracted sound formed with small ゃ / ゅ / ょ.
- A yoon combination counts as one mora.
- Full-sized や / ゆ / よ is pronounced separately.
- ん counst as one mora even when it appears after a yoon combination.

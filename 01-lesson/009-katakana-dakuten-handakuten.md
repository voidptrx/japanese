# Lesson 009 - Katakana Dakuten & Handakuten

## 1. What I learned

- I learned how dakuten (゛) changes certain katakana sounds.
- I learned how handakuten (゜) changes the ハ row.
- I understand these as transformations of existing kana rows rather than completely separate patterns.
- I can recognize dakuten and handakuten katakana individually and inside words.

## 2. Dakuten

Dakuten is the mark `゛`. It changes the sound of certain kana.

### The `カ` row

| ガ  | ギ  | グ  | ゲ  | ゴ  |
| :-: | :-: | :-: | :-: | :-: |
| ga  | gi  | gu  | ge  | go  |

The vowel pattern stays the same. The consonant changes from `k` to `g`.

### The `サ` row

| ザ  | ジ  | ズ  | ゼ  | ゾ  |
| :-: | :-: | :-: | :-: | :-: |
| za  | ji  | zu  | ze  | zo  |

> [!IMPORTANT]
> `ジ` is read as `ji`.

### The `タ` row

| ダ  | ヂ  | ヅ  | デ  | ド  |
| :-: | :-: | :-: | :-: | :-: |
| da  | ji  | zu  | de  | do  |

> [!IMPORTANT]
> `ヂ` is read as `ji`.
> `ヅ` is read as `zu`.
>
> `ヂ` and `ヅ` are less common than `ジ` and `ズ`.

### The `ハ` row

| バ  | ビ  | ブ  | ベ  | ボ  |
| :-: | :-: | :-: | :-: | :-: |
| ba  | bi  | bu  | be  | bo  |

Dakuten changes the consonant from `h` to `b`.

## 3. Handakuten

Handakuten is a small circle `゜`. It is used with the `ハ` row.

### The `ハ` row

Handakuten changes the row to the `p`-sound.

| パ  | ピ  | プ  | ペ  | ポ  |
| :-: | :-: | :-: | :-: | :-: |
| pa  | pi  | pu  | pe  | po  |

> [!IMPORTANT]
> Dakuten and handakuten produce different sounds.
>
> - ハ = ha
> - バ = ba
> - パ = pa

## 4. Main transformation patterns

The basic patterns learned in this lesson are:

- k -> g
- s -> z
- t -> d
- h -> b
- h -> p

The vowel pattern `a-i-u-e-o` remains consistent within each row.

The same transformation patterns apply to both hiragana and katakana.

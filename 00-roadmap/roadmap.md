# 日本語 — Japanese 0 → N5 Roadmap

## 🎯 Main Goal

Build a solid Japanese foundation from zero and reach JLPT N5 level.

The goal is not only to pass JLPT N5, but to actually understand and use basic Japanese.

### Learning principles

- Understand before memorizing.
- Learn Japanese according to Japanese sentence structure.
- Use Cure Dolly's structural approach where useful.
- Learn vocabulary in context.
- Learn kanji through words, not isolated characters.
- Practice reading and listening from the beginning.
- Record mistakes and review them.
- Prefer active recall over passive rereading.
- Reduce reliance on romaji as early as possible.

# Phase 9 — Kanji

## Target

Approximately 80–100 basic kanji.

### Milestones

- [ ] 25 kanji
- [ ] 50 kanji
- [ ] 75 kanji
- [ ] 100 kanji

### Learning principle

Do not learn kanji as isolated symbols.

Learn:

> Kanji → word → reading → meaning → sentence

Example:

> 日 → 日本 → 日本語 → 今日 → 毎日

### Milestone

- [ ] Recognize common N5 kanji

# 🏆 N5 Completion Criteria

I consider N5 complete when I can:

- [ ] Read hiragana comfortably
- [ ] Read katakana comfortably
- [ ] Recognize basic N5 kanji
- [ ] Understand basic Japanese sentence structure
- [ ] Explain common particles at a basic level
- [ ] Conjugate common verbs
- [ ] Use basic adjectives
- [ ] Understand core N5 grammar
- [ ] Understand simple written Japanese
- [ ] Understand slow/basic spoken Japanese
- [ ] Produce simple Japanese sentences
- [ ] Consistently perform well on N5-style practice questions

## Final principle

> **The goal is not to finish N5.**
>
> **The goal is to build a foundation strong enough to continue to N4 → N3 → N2 → N1.**
